the brief

Chris, verbatim

terminal-first, deterministic, fast

The ask was not “make slide authoring friendly.” It was: make the agentic workflow sharper for someone who lives in a terminal.

“i love the concept of this, but the execution is defintily for non techy people, which isn't me.”
“a tool that can help me build amazing presentations agentically, but with tooling to help make some of it more deterministic and fast”
“i don't really use gui's so it should have the workflow of a terminal based agentic flow with screenshots via rodney etc as the expected feedback mechanism”

$ minimal node dependencies

$ use code-minions for exploration; keep the primary agent on vision, delegation, and Chris

Shipping drama

incident report, v0.1.0

[bug-001]

first bug: sideshow check reported the forbidden <script> finding twice for one escaped <script></script> mention: open tag plus close tag. The only “Fixed” entry in the changelog.

[jj-time]

timing footgun: the oauth fix briefly amended the just-pushed release commit; a leftover maint workspace kept respawning empty commits during cleanup. History was repaired properly.

[release]

oauth archaeology: the linux release job died missing a pages.sr.ht oauth grant, a bug Chris had already fixed elsewhere that never propagated to the template.

[swarm]

parallel sessions colliding: fleet maintenance kept landing on sideshow’s main mid-task, surprising the agent: “I’m trying to trace through the git history here…”

Kinks found. That is exactly what shaking out the pipeline was for.
